4. 對高相似候選題逐欄核對 JSON 與 SQLite，避免只依題號、單一關鍵字或排序猜測。

- A：未見同題或足以覆蓋的等價題，可作為後續補入候選，但仍須完成必要審查。
- B：存在高度相似或考點重疊題，是否等價需人工／ChatGPT 裁定，不得直接補入。
