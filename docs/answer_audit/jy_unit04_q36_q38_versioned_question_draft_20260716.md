## 二、官方佐證摘要

- 《保險法》第13條現行及民國103年6月4日歷史版本均將人身保險分為人壽、健康、傷害及年金保險。
- 金管會《人身保險商品Q&A問答集》將投資型保險定義為人身保險，並說明投資型商品分為投資型人壽與投資型年金。
- 《人身保險商品審查應注意事項》亦將投資型人壽置於人壽保險、投資型年金置於年金保險項下。
- 因此投資型保險是人身保險商品型態，但不是《保險法》第13條之外的獨立第五類。

## 四、Q36 版本化草案

- subject：`B 保險實務-分類`
- unit：`04 人身保險意義、功能、分類`
- content：`依審查日有效之《保險法》第13條規定，人身保險包括下列哪四類？`
- options：
  1. `生存保險、死亡保險、生死合險、傷害保險`
  2. `人壽保險、傷害保險、健康保險、投資型保險`
  3. `人壽保險、健康保險、傷害保險、年金保險`
  4. `生存保險、死亡保險、生死合險、年金保險`
- correct_answer：`"3"`
- explanation：`依審查日有效之《保險法》第13條規定，人身保險包括人壽保險、健康保險、傷害保險及年金保險，因此答案為第3項。投資型保險依商品性質分為投資型人壽保險或投資型年金保險，並非第13條之外的獨立第五類。`

### 草案調整說明

- 將題幹明示法條及審查時點，避免被誤讀為無版本界線的教材陳述。
- 將正確選項順序改為與法條一致。
- 保留投資型保險作為干擾概念，但解析清楚說明其法律定位。
- 本草案與原稿答案位置同為第3項，但選項文字已版本化，不是原稿逐字複製。

- options：

  2. `ABC`
  3. `BC`

- correct_answer：`"2"`
- explanation：`傷害保險與健康保險均屬《保險法》第13條所列人身保險類別；投資型保險亦屬人身保險商品，依商品性質分為投資型人壽保險或投資型年金保險。責任保險則屬財產保險，因此答案為ABC。投資型保險並不是第13條之外的獨立第五類。`

- 解析明確說明投資型保險與人壽／年金類別的從屬關係。
